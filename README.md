# Coffee Sales Analysis using SQL

## Project Overview
This project analyzes coffee sales data across multiple cities using SQL. The objective is to generate business insights related to revenue, customer behavior, product performance, market potential, and sales growth.

## Dataset Tables
- City
- Customers
- Products
- Sales

## Business Questions Solved
- Coffee Consumers Count by City
- Total Revenue Analysis
- Product Sales Performance
- Average Sales per Customer
- Customer Segmentation
- Top Selling Products by City
- Monthly Sales Growth Analysis
- Rent vs Revenue Analysis
- Market Potential Analysis
- Business Recommendations

## SQL Concepts Used
- Joins
- Common Table Expressions (CTEs)
- Aggregate Functions
- GROUP BY
- ORDER BY
- Window Functions
- DENSE_RANK()
- LAG()
- Revenue Analysis
- Customer Segmentation

## Key Insights
- Identified top-performing cities based on revenue.
- Analyzed customer purchasing behavior.
- Evaluated market expansion opportunities.
- Measured month-over-month sales growth.
- Ranked top-selling products across cities.
